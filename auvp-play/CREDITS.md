# Créditos

## Inspiração

O **AUVP Tube** nasceu de uma ideia que não é minha. A extensão **AUVP Play**, criada por
**Matheus Satake de Souza** para o Google Chrome, foi quem pensou primeiro em substituir a
página inicial do YouTube por uma seleção dos canais da AUVP:

> https://chromewebstore.google.com/detail/auvp-play/akjmabmimndjlnbgficabihjclinbpdc

O mérito do conceito é dele. Se você usa Chrome, use a extensão dele — ela é a original.

## O que é este projeto

O AUVP Tube é uma extensão **independente** para o Mozilla Firefox, escrita por
**marcos123dev** (<https://github.com/marcos123dev>).

- **Não é a extensão do Matheus modificada, portada ou recompilada.** O código foi escrito
  do zero, a partir da descrição pública dos recursos. Nenhuma linha de código da extensão
  original foi copiada, descompilada ou redistribuída.
- É uma reconstrução para outro navegador, com implementação própria e diferenças de
  comportamento descritas no [README.md](README.md).
- Não há vínculo com o autor original, com a AUVP, com a AUVP Capital ou com os canais
  do YouTube citados. Esta extensão não é oficial.

## Link de indicação

O botão "Seja aluno" usa o **link de indicação do autor desta extensão**, e não o do autor
original. Se alguém se inscrever na AUVP por esse botão, quem pode receber comissão é
marcos123dev. O botão está identificado como tal, só abre quando clicado e a extensão nunca
altera links do YouTube nem insere código de indicação em páginas de terceiros.
