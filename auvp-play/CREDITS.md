# Créditos

## Autoria original

Esta extensão é **baseada na extensão original para Google Chrome chamada "AUVP Play",
criada por Matheus Satake de Souza**, publicada na Chrome Web Store:

> https://chromewebstore.google.com/detail/auvp-play/akjmabmimndjlnbgficabihjclinbpdc

A ideia, o conceito, o nome e o conjunto de funcionalidades pertencem ao autor original.
Todo o mérito pela criação da extensão é dele.

## O que é este projeto

Este é um **port independente e não oficial para o Mozilla Firefox**.

- O código-fonte foi **escrito do zero**, a partir da descrição pública das
  funcionalidades da extensão original. **Nenhuma linha de código da extensão original
  foi copiada, descompilada ou redistribuída.**
- É uma reimplementação (reconstrução) das funcionalidades, não uma cópia do pacote.
- Não há qualquer vínculo com o autor original, com a AUVP, com a AUVP Capital ou com
  os canais do YouTube citados.
- O link "Seja aluno" aponta para o site público da AUVP **sem nenhum código de
  indicação/afiliado**. O código de indicação da extensão original pertence ao autor
  original e não foi reproduzido aqui.

## Marcas

"AUVP", "AUVP Capital", "AUVP Agro", "AUVP Atlas" e "Investidor Sardinha" são marcas e
canais de seus respectivos titulares. "YouTube" é marca do Google LLC. Este projeto não
é afiliado, patrocinado nem endossado por nenhum deles.

## Pedido de remoção

Se o autor original ou qualquer titular de direitos quiser que esta versão deixe de
circular, basta pedir: o projeto é de uso pessoal e deve ser excluído a pedido.
